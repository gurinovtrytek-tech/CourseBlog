# CourseBlog
Консольный прототип блога для курса «Командное проектирование и разработка».

## Запуск
Windows с .NET Framework 4.8. Запустить run.cmd. Сборка без сторонних пакетов: build.cmd.
В Visual Studio открыть CourseBlog.sln. Целевая платформа — .NET Framework 4.8. Для сборки в Visual Studio нужен соответствующий targeting pack.
Приложение не требует MySQL. Данные сохраняются в data/blog.xml относительно текущей папки. Не запускайте две копии с одной папкой данных одновременно.

## Меню
Enter раскрывает меню, стрелки вверх и вниз выбирают пункт, Enter запускает его. Esc сворачивает меню, а в свёрнутом состоянии завершает программу.
Для обычного числового меню: bin/CourseBlog.exe --line-menu.
Три функции: просмотр статей, добавление статьи, просмотр и добавление комментариев. Пустые поля и неверные идентификаторы отклоняются.

## История Git
master — итог; final — объединение; feature/view, feature/add, feature/comments — функции.
Обмен изменениями проверен через локальный bare-репозиторий shared.git. Публикация GitHub и приглашение участника не выполнялись. Все изменения сделаны одним автором.
Git bundle сохраняет историю: git clone -b master CourseBlog.bundle restored-blog.
Учебный email автора student@example.test не является адресом для связи.
