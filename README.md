# CourseBlog
Небольшой учебный блог с комментариями.

## Запуск
Открыть CourseBlog.sln в Visual Studio и запустить проект. Можно запустить run.cmd.
Данные сохраняются в data/blog.xml.

## Меню
Enter открывает список, стрелки выбирают пункт, Enter запускает его. Есть просмотр статей, добавление статьи и комментарии.

Репозиторий закрыт и используется только для учебной работы.
